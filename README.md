## 📦 Projects

### 🚘 Car Pay-in — 차량 내 주차 결제 시스템
> AAOS 차량 앱 기반 QR 로그인 → 카드 등록 → 입차 → 결제 → 출차 전 과정 구현

* **Backend**: FastAPI 마이크로서비스 4개 (carpayin / pms / mock-pg / mock-card)
* **AWS**: ECS Fargate · RDS PostgreSQL · ElastiCache · SQS · Lambda · IoT Core · Cognito
* **Android**: AAOS Kotlin 앱, AWS IoT Core MQTT 실시간 입차 알림
* **CI/CD**: GitLab CI → AWS ECR 빌드 → ECS / EC2 SSM 자동 배포
* **Testing**: TDD — Fake/Stub 패턴으로 단위·API 테스트 후 CI 파이프라인 연동

### 📡 Connected Car Telemetry — 실시간 차량 텔레메트리 플랫폼
> 다수 커넥티드카의 실시간 주행 데이터를 수집·저장·시각화하는 데이터 파이프라인

* **Pipeline**: 차량 시뮬레이터 → Kafka → MongoDB Consumer → Query API
* **Frontend**: React + TypeScript 실시간 대시보드
* **Infra**: Kubernetes + Helm, Jenkins CI/CD, Prometheus + Grafana 모니터링
